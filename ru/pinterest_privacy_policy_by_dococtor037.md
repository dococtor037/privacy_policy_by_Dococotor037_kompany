# Политика конфиденциальности для Pinterest-приложения

**Дата вступления в силу:** 2 июня 2026

## Введение
Данное приложение (далее — "Приложение") создано для автоматической публикации изображений на Pinterest.

## Сбор и использование информации
Приложение **не собирает, не хранит и не передает** какие-либо личные данные пользователей. Оно использует официальный Pinterest API исключительно для публикации контента по вашему прямому указанию.

## Третьи стороны
Приложение не передает никакие данные третьим лицам.

## Безопасность
Все операции по загрузке и публикации изображений выполняются на вашем локальном сервере.

## Изменения в Политике конфиденциальности
Мы можем обновлять данную Политику конфиденциальности. Рекомендуем периодически проверять этот документ на предмет изменений.
